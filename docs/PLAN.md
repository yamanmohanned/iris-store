## 1) الرؤية والأهداف

متجر إلكتروني احترافي **(موقع ويب فقط في الوقت الحالي)** يحقق ثلاثة أهداف:

| الهدف | ماذا يعني عملياً |
|---|---|
| **سهولة التسوق للزبون** | تصميم Mobile-first، شراء بدون حساب (Guest checkout)، الدفع عند الاستلام، خطوات قليلة، بحث يفهم العربية، تتبع الطلب برقم الطلب + رقم الهاتف. |
| **سهولة الإعداد والإدارة للمالك** | معالج إعداد أول تشغيل (Setup wizard) يضبط الدولة والعملة والمحافظات تلقائياً، لوحة تحكم بسيطة تعمل على الهاتف، ترتيب أقسام الصفحة الرئيسية بدون برمجة، صلاحيات للموظفين. |
| **أمان عالٍ جداً** | تشفير كلمات المرور Argon2id، تحقق بالرمز (OTP)، تحقق بخطوتين إلزامي للإدارة، تحديد معدل الطلبات، حماية CSRF/XSS/IDOR، سجل تدقيق، اختبارات أمنية. |

## 2) القرارات التقنية (Tech Stack)

| الطبقة | الاختيار | لماذا |
|---|---|---|
| الإطار | **Next.js 16** (App Router) + React 19 | عرض من الخادم (SSR) لسرعة الهاتف وتحسين الظهور في Google، واجهة وخادم في مشروع واحد = إعداد أسهل. |
| اللغة | **TypeScript** (strict) | أمان الأنواع يقلل الأخطاء. |
| التنسيق | **Tailwind CSS 4** + متغيرات CSS (Design tokens) | دعم RTL ممتاز، وتطابق مباشر مع كود Stitch (الذي يُصدَّر بـ Tailwind)، وتغيير ألوان الهوية من لوحة التحكم. |
| مكونات الواجهة | Radix UI + مكونات خاصة، أيقونات lucide | مكونات سهلة الوصول (Accessibility) وتعمل باللمس. |
| تعدد اللغات | **next-intl** — العربية افتراضياً (RTL) + الإنجليزية | المتجر عربي أولاً مع دعم الإنجليزية. |
| قاعدة البيانات | **PostgreSQL 16** + **Drizzle ORM** | معاملات (Transactions) موثوقة للطلبات والمخزون، قيود على مستوى القاعدة، ترحيلات (Migrations) مُراجَعة. |
| المصادقة | **Better Auth** + Argon2id | مكتبة حديثة مُصانة: كلمات مرور، رموز OTP بالبريد، دخول بدون كلمة مرور، تحقق بخطوتين TOTP، تحديد معدل. |
| التحقق من المدخلات | **Zod** | كل مدخل يُتحقق منه على الخادم. |
| الصور | sharp + فحص نوع الملف الحقيقي | إعادة ترميز الصور (WebP) وحذف البيانات الوصفية (الموقع GPS) وأحجام متعددة للهاتف. |
| البريد | طبقة مزودين: Console / SMTP / Resend + صندوق صادر (Outbox) مع إعادة محاولة | لا تضيع رسالة تأكيد طلب إذا تعطل المزود. |
| الاختبارات | **Vitest** (وحدات + تكامل على PostgreSQL حقيقي) + **Playwright** (E2E على مقاسات الهاتف) | ثقة قبل أي نشر. |
| النشر | Docker (standalone) + docker-compose (التطبيق + القاعدة + Caddy للـ HTTPS) — وبديل: Vercel + Neon | يمكن تشغيله على أي خادم بأمر واحد. |

## 4) أولويات الميزات (ما لا يمكن الاستغناء عنه وما يمكن تأجيله)

### ✅ أساسي — لا يمكن الاستغناء عنه (MVP)
- الأقسام والمنتجات مع الخيارات (مقاس/لون) والصور والمخزون.
- البحث (يفهم اختلاف الهمزات والتاء المربوطة والياء).
- السلة + إتمام الطلب **بدون حساب** + **الدفع عند الاستلام**.
- مناطق التوصيل وأجورها (محافظات/مدن).
- صفحة تأكيد الطلب + **تتبع الطلب** برقم الطلب ورقم الهاتف.
- حساب الزبون: تسجيل + تحقق OTP + دخول + استعادة كلمة المرور + طلباتي + عناويني.
- لوحة التحكم: المنتجات، الأقسام، الطلبات (تغيير الحالة)، الزبائن، الإعدادات، التوصيل.
- إشعارات البريد (رمز التحقق، تأكيد الطلب، تغيّر الحالة).
- صفحات السياسات (الخصوصية، الاستبدال والاسترجاع، الشروط) + SEO أساسي.
- الأمان الكامل + التصميم المتجاوب للهاتف.

### ⭐ مهم — يُبنى في هذا الإصدار
- كوبونات الخصم، المفضلة، **ترتيب أقسام الصفحة الرئيسية من لوحة التحكم**.
- صلاحيات الموظفين + سجل التدقيق + تنبيه نفاد المخزون.
- طباعة الفاتورة/قائمة التجهيز، إحصائيات لوحة التحكم.
- زر واتساب للتواصل، قابلية التثبيت على الهاتف (PWA).

### 🔜 يمكن تأجيله (بعد الإطلاق)
- تقييمات المنتجات، توصيات ذكية، رسائل السلة المتروكة، النشرة البريدية، المدونة.
- بطاقات الهدايا، نقاط الولاء، تعدد العملات.
- الدفع الإلكتروني (يحتاج قرارك — انظر القسم 6).
- التحقق برقم الهاتف عبر SMS/WhatsApp (يحتاج مزوداً مدفوعاً).

### ❌ خارج النطاق حالياً
- تطبيقات الهاتف الأصلية (iOS/Android) — **البنية جاهزة لإضافة API لها لاحقاً**.
- تعدد البائعين (Marketplace)، نقاط البيع (POS)، الاشتراكات، تعدد المستودعات.

## 5) مبادئ الأمان المعتمدة (ملخص — التفاصيل في `SECURITY.md`)

1. **لا ثقة بالمتصفح**: الأسعار والمخزون والخصومات تُحسب على الخادم داخل معاملة قاعدة بيانات.
2. **كلمات المرور**: Argon2id + حد أدنى 10 أحرف + منع كلمات المرور الشائعة.
3. **الجلسات**: كوكيز HttpOnly + Secure + SameSite، تُخزَّن في القاعدة ويمكن إلغاؤها.
4. **التحقق بالرمز**: OTP من 6 أرقام، صلاحية 10 دقائق، عدد محاولات محدود، يُخزَّن مُشفَّراً (hash).
5. **التحقق بخطوتين إلزامي** لكل حساب إداري (المالك والموظفين).
6. **تحديد معدل الطلبات** على الدخول والتسجيل وإرسال الرموز وإتمام الطلب والتتبع.
7. **ترويسات أمان** صارمة: CSP بـ nonce، HSTS، منع التضمين (Clickjacking).
8. **الصلاحيات تُفحص على الخادم** في كل عملية، وليس في الواجهة فقط.
9. **رفع الملفات**: فحص النوع الحقيقي، حد للحجم، إعادة ترميز، أسماء عشوائية.
10. **سجل تدقيق** لكل عملية إدارية وحدث أمني.
