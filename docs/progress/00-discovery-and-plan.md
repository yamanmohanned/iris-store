# ملخص المرحلة 0 — الاكتشاف ووضع الخطة

**التاريخ:** 2026-10-05 · **الفرع:** `claude/nifty-turing-csz4ep`

## ما تم إنجازه

1. **فحص المستودع:** كان فارغاً (ملف README فقط) — بدأنا البناء من الصفر.
2. **محاولة الوصول لمشروع Stitch رقم `1055627941288859978`:**
   - لا يوجد موصل (Connector) لـ Stitch في هذه الجلسة.
   - تم التأكد أن خادم Stitch MCP (`https://stitch.googleapis.com/mcp`) **يعمل ويمكن الوصول إليه**، وأدواته
     معروفة (`get_project`, `list_screens`, `get_screen`, `list_design_systems` ...)، لكنه **يتطلب مفتاح API**.
   - تم تجهيز سكربت جاهز `scripts/stitch-sync.mjs` يسحب كل شاشات المشروع (HTML + صور) ونظام التصميم إلى
     مجلد `design/stitch/` بمجرد توفر المفتاح.
3. **وضع الخطة الكاملة** في [`docs/PLAN.md`](../PLAN.md): الأهداف، القرارات التقنية، 9 مراحل، أولويات
   الميزات (الأساسي / المهم / المؤجل / خارج النطاق)، مبادئ الأمان، القرارات المصيرية المؤجلة، خريطة الصفحات.
4. **ملف `CLAUDE.md`** في جذر المشروع: دليل مختصر يُقرأ تلقائياً في كل جلسة جديدة (الأوامر، البنية، القواعد).
5. **ملف التسليم `docs/HANDOFF.md`**: نقطة البداية لأي جلسة جديدة.

## ما تحتاج أن تفعله أنت (للمرحلة 8)

لكي أتمكن من تحليل تصميمك في Stitch:

1. افتح Stitch ← الإعدادات (Settings) ← مفاتيح API (API Keys) ← أنشئ مفتاحاً.
2. أضفه في إعدادات البيئة (قائمة البيئة في شريط عنوان الجلسة ← Edit) كمتغير باسم **`STITCH_API_KEY`**.
3. ابدأ جلسة جديدة — سيتم التقاط المفتاح تلقائياً. **لا تلصق المفتاح في المحادثة.**

بديل: صدّر الشاشات من Stitch (كود + صور) وضعها في المجلد `design/stitch/` داخل المستودع.

## القرارات المتخذة

- موقع ويب فقط (Next.js) بتصميم Mobile-first، والبنية قابلة لإضافة تطبيق هاتف لاحقاً.
- العربية لغة افتراضية (RTL) مع دعم الإنجليزية.
- الدفع عند الاستلام + التحويل البنكي في البداية؛ الدفع الإلكتروني لاحقاً حسب الدولة.
- التحقق بالبريد الإلكتروني (OTP)؛ التحقق بالهاتف لاحقاً عند اختيار مزود SMS.
