# ملخص المرحلة 2 — قاعدة البيانات

**الحالة:** ✅ مكتملة · **الفرع:** `claude/nifty-turing-csz4ep`

## ما تم إنجازه

### 1) المخطط الكامل (30 جدولاً) — انظر [`docs/DATABASE.md`](../DATABASE.md)

- الهوية: المستخدمون والجلسات والحسابات ورموز التحقق والتحقق بخطوتين (متوافق مع Better Auth).
- الكتالوج: أقسام شجرية (حتى 3 مستويات)، منتجات بخيارات (مقاس/لون) ونسخ (Variants) بسعر ومخزون مستقل،
  صور مرتبة، وسوم، علامة تجارية، حقول SEO.
- التجارة: السلة، العناوين، المفضلة، مناطق التوصيل، الكوبونات، الطلبات وعناصرها وخط زمني لأحداثها، حركات المخزون.
- المحتوى: الإعدادات، الصفحات الثابتة، أقسام الصفحة الرئيسية القابلة للترتيب.
- النظام: سجل التدقيق، عدّادات تحديد المعدل، صندوق الإشعارات الصادرة (Outbox).

### 2) حماية على مستوى قاعدة البيانات (لا تعتمد على الكود فقط)

- قيود تمنع: مخزوناً سالباً، أسعاراً سالبة، "سعر قبل الخصم" أقل من السعر، كوبون بنسبة > 100%،
  بريداً بأحرف كبيرة، أدواراً غير معروفة، كمية سلة خارج 1–999.
- أرقام طلبات متسلسلة تبدأ من **#10001**، ومفتاح منع التكرار (Idempotency) لكل طلب.
- **سجل التدقيق غير قابل للتعديل أو الحذف** (Trigger في القاعدة) إلا بمهمة أرشفة صريحة.

### 3) الخدمات الأساسية (`src/server/services/`)

| الخدمة                  | الوظيفة                                                                                                                                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `settings.ts`           | إعدادات المتجر بأقسام (عام، الهوية، الدفع، الإشعارات، SEO) مع قيم افتراضية وتحقق وتسجيل تدقيق وتخزين مؤقت.                                                                                            |
| `media.ts` + `storage/` | رفع الصور: فحص النوع الحقيقي، حد 10MB، حماية من "قنابل الضغط"، إعادة الترميز WebP بـ 5 مقاسات، **حذف بيانات GPS/الكاميرا**، تخزين محلي أو S3/R2.                                                      |
| `catalog-admin.ts`      | حفظ المنتج كاملاً في معاملة واحدة، روابط عربية تلقائية بلا تكرار، تنقية الوصف من XSS، **تعديل المخزون كفرق لا كقيمة** (لا يضيع بيع حدث أثناء التعديل)، كشف التعديل المتزامن، منع العبث بنسخ منتج آخر. |
| `content.ts`            | أقسام الرئيسية (بانر متحرك، أقسام، منتجات، إعلان، مزايا، نص) بإعدادات مُتحقق منها، والصفحات الثابتة.                                                                                                  |
| `audit.ts`              | تسجيل كل عملية إدارية.                                                                                                                                                                                |

### 4) أدوات عامة (`src/lib/`)

- `search.ts`: توحيد النص العربي للبحث (أ/إ/آ → ا، ة → ه، ى → ي، الأرقام الهندية → لاتينية، إزالة التشكيل).
- `money.ts`: تنسيق الأسعار بأرقام لاتينية ورمز عربي نظيف (`25,000 د.ع`).
- `slug.ts`: روابط عربية مقروءة (`/p/فستان-صيفي`).
- `countries.ts`: **9 دول جاهزة** (العراق، السعودية، الإمارات، الكويت، قطر، البحرين، عُمان، الأردن، مصر)
  بالعملة ورمز الهاتف والمنطقة الزمنية وكل المحافظات/المناطق.

### 5) البيانات الأولية (Seed)

- `pnpm db:seed`: متجر جديد جاهز — إعدادات الدولة، مناطق التوصيل (19 محافظة للعراق)، 5 صفحات سياسات
  احترافية بالعربية والإنجليزية (من نحن، الشحن، الاستبدال، الخصوصية، الشروط)، وتخطيط للصفحة الرئيسية.
- `pnpm db:seed:demo`: كتالوج تجريبي — 6 أقسام، 18 منتجاً (منها بخيارات لون ومقاس، ومنتج نافد، ومنتجات
  بخصم)، صور مولّدة محلياً، كوبون `WELCOME10`.

## الاختبارات

**50 اختباراً ناجحاً** (24 وحدات + 26 تكامل على PostgreSQL حقيقي)، منها اختبارات أمنية:
رفض SVG/HTML المتنكر كصورة، حذف بيانات EXIF، منع XSS في الوصف، منع المخزون السالب، حماية سجل التدقيق.

## التالي: المرحلة 3 — المصادقة والأمان

Better Auth: تسجيل + تحقق بالرمز (OTP) عبر البريد، دخول بكلمة مرور أو برمز، استعادة كلمة المرور،
تحقق بخطوتين إلزامي للإدارة، صلاحيات الأدوار، تحديد المعدل، قفل الحساب، معالج الإعداد الأول للمالك.
